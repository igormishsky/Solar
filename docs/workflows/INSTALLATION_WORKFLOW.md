# Installation Process Workflow

## Overview

This document details the complete workflow for solar panel installation projects, from initial customer contact through commercial activation with the Israel Electric Corporation (IEC / חברת החשמל).

## Phase 1: Pre-Installation

### 1.1 Lead Capture

**Trigger:** Customer inquiry via phone, website, or referral

**Actions:**
- Create customer record in CRM
- Capture initial requirements
- Schedule site survey

**System Tasks:**
- [ ] Create customer profile
- [ ] Log initial contact details
- [ ] Generate site survey task

**Duration:** Same day

---

### 1.2 Site Survey

**Trigger:** Site survey appointment confirmed

**Actions:**
- Visit property
- Assess roof condition, orientation, shading
- Take measurements and photos
- Verify electrical infrastructure
- Collect property documentation

**Required Data:**
- Roof dimensions and area
- Roof material and condition
- Orientation and tilt angle
- Shading analysis
- Electrical panel capacity
- Meter location and type

**System Tasks:**
- [ ] Upload site photos
- [ ] Record survey measurements
- [ ] Complete site assessment form

**Duration:** 1-2 hours on-site

---

### 1.3 Proposal & Quote

**Trigger:** Site survey completed

**Actions:**
- Design preliminary system layout
- Calculate system size and expected production
- Prepare financial analysis (ROI, payback period)
- Generate formal quotation

**Documents Generated:**
- System proposal (PDF)
- Price quotation
- Expected production forecast

**System Tasks:**
- [ ] Generate system proposal
- [ ] Create price quote
- [ ] Send to customer

**Duration:** 1-3 business days

---

### 1.4 Contract Signing

**Trigger:** Customer accepts quote

**Actions:**
- Review terms with customer
- Sign installation contract
- Process initial payment (if applicable)
- Initiate project in system

**Documents Required:**
- Signed installation contract
- Customer ID copy
- Property ownership/rental documents

**System Tasks:**
- [ ] Upload signed contract
- [ ] Process payment
- [ ] Create project record
- [ ] Transition to active project

**Duration:** Same day

---

## Phase 2: Planning & Permits

### 2.1 System Design

**Trigger:** Contract signed

**Actions:**
- Create detailed engineering design
- Panel layout optimization
- Electrical schematic
- Structural assessment (if needed)

**Documents Generated:**
- תוכנית פריסה + הארקה (Layout Plan + Grounding)
- Electrical diagrams
- Structural calculations

**Professionals Required:**
- מתכנן (Planner)
- מהנדס חשמל (Electrical Engineer)
- קונסטרוקטור (Constructor) - if required

**System Tasks:**
- [ ] Assign planner to project
- [ ] Upload design documents
- [ ] Get engineering approval

**Duration:** 3-5 business days

---

### 2.2 Permit Process

**Trigger:** Design approved

**Actions:**
- Submit permit application (if required)
- Wait for municipal approval
- Address any feedback

**Documents Required:**
- דיווח על עבודה פטורה מהיתר (Permit-Exempt Work Report)
- OR full building permit application

**System Tasks:**
- [ ] Generate permit documents
- [ ] Track permit status
- [ ] Upload approval

**Duration:** 1-4 weeks (depending on municipality)

---

### 2.3 IEC Initial Request

**Trigger:** Permit approved

**Stage:** REQUEST_OPENING (פתיחת בקשה)

**Actions:**
- Submit initial connection request to IEC
- Pay application fees
- Receive request confirmation

**System Tasks:**
- [ ] Generate IEC application
- [ ] Track payment
- [ ] Log confirmation number

**Duration:** 1-2 business days

---

## Phase 3: Installation

### 3.1 Equipment Ordering

**Trigger:** IEC request submitted

**Actions:**
- Order solar panels
- Order inverter(s)
- Order mounting system
- Order electrical components

**System Tasks:**
- [ ] Create equipment order
- [ ] Track delivery dates
- [ ] Log equipment receipt

**Duration:** 1-2 weeks

---

### 3.2 Physical Installation

**Trigger:** Equipment received, installation team scheduled

**Actions:**
- Install mounting system
- Install solar panels
- Install inverter(s)
- Complete electrical connections
- Install monitoring system

**Professionals Required:**
- הקבלן המתקין (Installing Contractor)
- חשמלאי מבצע (Executing Electrician)
- קונסטרוקטור (Constructor)

**Documents Generated:**
- הצהרת חשמלאי מבצע (Executing Electrician Declaration)
- אישור קונסטרוקטור (Constructor Approval)

**System Tasks:**
- [ ] Assign installation team
- [ ] Log daily progress
- [ ] Upload installation photos
- [ ] Generate electrician declaration
- [ ] Generate constructor approval

**Duration:** 1-3 days (depending on system size)

---

### 3.3 Testing & Inspection

**Trigger:** Physical installation complete

**Actions:**
- System testing and commissioning
- Independent inspection by certified electrician
- Performance verification

**Professionals Required:**
- חשמלאי בודק (Inspecting Electrician)
- יבואן/יצרן מהפכים (Inverter Importer/Manufacturer)

**Documents Generated:**
- תצהיר התקנה לפי תקנה 24 (Installation Declaration per Regulation 24)
- טופס בדיקת מתקן פוטו-וולטאי (PV Installation Inspection Form)
- תצהיר כיול מהפכים (Inverter Calibration Affidavit)

**System Tasks:**
- [ ] Schedule inspection
- [ ] Upload test results
- [ ] Generate inspection forms
- [ ] Log any issues found

**Duration:** 1-2 days

---

## Phase 4: IEC Synchronization

### 4.1 Department Response

**Stage:** DEPARTMENT_RESPONSE (תשובת מחלק)

**Trigger:** IEC reviews initial request

**Actions:**
- Receive IEC response
- Address any technical requirements
- Submit additional documentation if needed

**System Tasks:**
- [ ] Log IEC response
- [ ] Create tasks for requirements
- [ ] Track resolution

**Duration:** 5-15 business days

---

### 4.2 Sync Compliance Check

**Stage:** SYNC_COMPLIANCE_REQUEST (בדיקת עמידה בתנאי סינכרון)

**Trigger:** All installation documents complete

**Actions:**
- Submit compliance verification request
- Include all required forms and certificates

**Documents Required:**
- טופס מרכז לעמידה בתנאי סף (Threshold Compliance Form)
- All professional declarations
- Test reports

**System Tasks:**
- [ ] Verify all documents complete
- [ ] Generate compliance package
- [ ] Submit to IEC
- [ ] Track response

**Duration:** 5-10 business days

---

### 4.3 Synchronization Request

**Stage:** SYNC_REQUEST (הגשת בקשה לסינכרון)

**Trigger:** Compliance approved

**Actions:**
- Submit formal synchronization request
- Schedule IEC inspection (if required)

**Documents Required:**
- טופס 1400 (Form 1400)
- הסכם PV (PV Agreement) - signed by customer

**System Tasks:**
- [ ] Generate sync request
- [ ] Schedule IEC visit
- [ ] Prepare site for inspection

**Duration:** 5-15 business days

---

### 4.4 Synchronization

**Stage:** SYNCHRONIZATION (סינכרון)

**Trigger:** Sync request approved

**Actions:**
- IEC performs final connection
- System synchronized to grid
- Initial meter reading recorded

**System Tasks:**
- [ ] Log sync completion date
- [ ] Record meter reading
- [ ] Update project status

**Duration:** 1-5 business days

---

### 4.5 Commercial Activation

**Stage:** COMMERCIAL_ACTIVATION (הפעלה מסחרית)

**Trigger:** Synchronization complete

**Actions:**
- Commercial operation begins
- Billing starts
- Customer receives confirmation

**System Tasks:**
- [ ] Update project to COMMERCIALLY_ACTIVE
- [ ] Set commercial activation date
- [ ] Send customer notification

**Duration:** Same day as sync

---

### 4.6 Standing Order Form

**Stage:** STANDING_ORDER_FORM (טופס הוראת קבע)

**Trigger:** Commercial activation complete

**Actions:**
- Set up payment arrangements
- Complete standing order form
- Establish ongoing billing relationship

**System Tasks:**
- [ ] Generate standing order form
- [ ] Get customer signature
- [ ] Submit to billing system

**Duration:** 1-3 business days

---

## Phase 5: Post-Installation

### 5.1 Handover

**Trigger:** All documentation complete

**Actions:**
- Customer orientation and training
- Provide system documentation
- Set up monitoring access
- Explain warranty terms

**Documents Provided:**
- System manual
- Warranty certificates
- Monitoring access credentials
- Maintenance schedule

**System Tasks:**
- [ ] Complete handover checklist
- [ ] Upload final documents
- [ ] Enable monitoring integration
- [ ] Schedule first maintenance

**Duration:** 1-2 hours

---

### 5.2 Ongoing Monitoring

**Trigger:** Handover complete

**Actions:**
- Continuous performance monitoring
- Automatic alerts for issues
- Periodic performance reports
- Scheduled maintenance reminders

**System Tasks:**
- [ ] Configure monitoring connection
- [ ] Set alert thresholds
- [ ] Schedule periodic reports
- [ ] Set maintenance reminders

**Duration:** Ongoing

## Alerts & Notifications

### Automated Alerts

| Trigger | Alert Type | Recipients |
|---------|------------|------------|
| Stage pending > 7 days | Warning | Project Manager |
| IEC response received | Info | Project Manager, Office Staff |
| License expiring (30 days) | Warning | Admin, Professional |
| Document missing | Warning | Assigned Staff |
| Inspection failed | Critical | Project Manager, Technician |
| Commercial activation | Info | Customer, Project Manager |

### Customer Notifications

| Stage | Notification |
|-------|--------------|
| Contract signed | Welcome + project initiation |
| Installation scheduled | Installation date confirmation |
| Installation complete | Completion + next steps |
| Sync request submitted | Status update |
| Commercial activation | Congratulations + monitoring access |

## Exception Handling

### Common Issues & Resolutions

| Issue | Resolution |
|-------|------------|
| Roof structural concerns | Engage constructor for reinforcement assessment |
| IEC request rejected | Review requirements, resubmit with corrections |
| Failed inspection | Address issues, reschedule inspection |
| Customer payment delay | Pause project, notify customer |
| Equipment delay | Adjust schedule, notify customer |
| Permit issues | Engage with municipality, provide documentation |

### Escalation Path

1. **Level 1:** Assigned technician/staff
2. **Level 2:** Project Manager
3. **Level 3:** Operations Director
4. **Level 4:** General Manager

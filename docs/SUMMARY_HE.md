# O.R.I SOLAR - סיכום מערכת ניהול

## סקירה כללית

מערכת ניהול מקיפה עבור O.R.I SOLAR, המתמחה בהתקנת פאנלים סולאריים, ניטור ביצועים ושירותי תחזוקה ללקוחות פרטיים, עסקיים ומוסדיים.

## מודולים עיקריים

### 1. ניהול לקוחות (CRM)

- פרופילי לקוח מלאים
- היסטוריית התקנות ותחזוקה
- תיעוד פניות שירות, תקלות ופתרונות
- סיווג לקוחות (פרטי/עסקי/מוסדי)
- דש-בורד למנהלים

### 2. ניהול פרויקטים

- יצירת פרויקטים חדשים
- שיוך בעלי מקצוע
- מעקב אחר שלבי ביצוע
- תיעוד התקדמות

### 3. מעקב תהליך התקנה (מול חח"י)

```
פתיחת בקשה → תשלום → תשובת מחלק → בדיקת תנאי סינכרון
    → הגשת בקשה לסינכרון → סינכרון → הפעלה מסחרית → הוראת קבע
```

### 4. ניהול משימות ותיאום צוותים

- יצירת והקצאת משימות
- מעקב סטטוס בזמן אמת
- ממשק נייד לעדכון מהשטח
- התראות ותזכורות

### 5. ניטור ביצועים

- חיבור למערכות ניטור (SolarEdge, Enphase וכו')
- גרפים ונתוני תפוקה
- התרעות אוטומטיות
- תיעוד פעולות תחזוקה

### 6. דוחות ומסמכים

- דוחות ביצועים תקופתיים
- הפקת חשבוניות והצעות מחיר
- ייצוא נתונים
- ניהול מסמכים מצורפים
